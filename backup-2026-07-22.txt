1. Git 초기화 및 원격 저장소 연결
===============================================================================
- 실제 프로젝트 루트는 fullstackshop/fullstackshop 하위 폴더로 확인됨.
- 해당 폴더에서 `git init` 실행.

- .gitignore에 .env* 가 이미 포함되어 있어 비밀값 노출 없이 안전하게 최초 커밋 진행.

- `git push -u origin main` 으로 GitHub main 브랜치에 반영 완료.
